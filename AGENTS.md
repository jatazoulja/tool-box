# Agent instructions

The canonical repository instructions are in [GEMINI.md](GEMINI.md). Read it in full before making changes.

For task-specific detail, follow the relevant resource it names under `.agents/rules/` or `.agents/skills/`. If guidance conflicts, `GEMINI.md` takes precedence; then use the rule or skill specific to the task.

Use Yarn as the package manager and verify implementation changes with `yarn build`.
